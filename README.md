# Tomatoro 🍅 — ИИ-напарник по фокусу

Таймер по методу Помодоро с ИИ-напарником: замечает отвлечения и возвращает к работе.
Заявка на конкурс **Sber500xDisrupt** (Productivity & Work — «Напарник по фокусу», трек 1).

## Продукт

- **Веб-кабинет** (Next.js): таймер, задачи (День → Помодоро → Спринт → Задача), аналитика с трендом, геймификация, тарифы
- **Браузерное расширение** (Manifest V3, WXT): фиксирует уход с рабочей вкладки локально — на сервер уходит только факт ухода, без URL
- **ИИ-напарник Томаторо** (GigaChat): уведомление при уходе с эскалацией эмоций 4/8/12 мин, озвучка SaluteSpeech, утренний план, итоги дня
- **Геймификация**: очки фокуса, уровни-сорта помидоров, Помидорки за день без срывов (оплата подписки до 100%)

## Стек

Next.js · Tailwind · WXT (MV3) · FastAPI · Celery/Redis · PostgreSQL (Supabase) · GigaChat → YandexGPT → fallback · SaluteSpeech · Web Push · ЮKassa

## Структура репозитория

```
landing/   — лендинг и страницы-ресурсы (index, demo, extension, presentation)
docs/      — системный анализ: требования, user flows, архитектура, ER-модель, API, ИИ-оркестратор, безопасность
src/       — код приложения (в разработке)
```

## Приватность

На сервер не попадают: URL вкладок, скриншоты, камера, история браузера. Только факт ухода и текст цели, которую пользователь написал сам. Подробно — `docs/07_безопасность_и_приватность.md`.
